# Mini ERP CRM
A full-stack Mini ERP CRM system for managing customers, products, sales, orders, and business reports.
##Features

- Customer management
- Product management
- Sales management
- Order management
- Sales history
- Sales cancellation
- Inventory management
- Reports and analytics
- Customer and product statistics
- REST API based backend

## Tech Stack

### Frontend
- React
- Vite
- JavaScript / TypeScript
- CSS

### Backend
- Node.js
- Express.js
- TypeScript
- Prisma ORM
- MySQL

### Database
- MySQL
